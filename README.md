# DHA Multan Estates

Portfolio website for a property dealer in DHA Multan: plots, houses and plot files, with drone video and property shoots.

**Live site:** https://therideconnect23-max.github.io

## Features
- Drone-viewfinder hero over an animated plot map
- Scroll animations (GSAP + ScrollTrigger) and smooth scrolling (Lenis)
- Property shoot showreel, photo gallery with lightbox
- Plot size guide (Marla / Kanal in sq ft)
- Client reviews section with Urdu (Nastaliq) support
- Contact form that opens WhatsApp with the message ready to send

## Edit
Open `index.html` and change the block marked `EDIT THESE` near the bottom:
- `WHATSAPP` – your number with country code, e.g. `923001234567`
- `TESTIMONIALS` – real client reviews

Plain HTML, CSS and JavaScript. No build step.
